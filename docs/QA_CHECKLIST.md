# 真机 / 模拟器验收清单

> 每轮 UX/调度/通知变更后按表勾选。`npm run typecheck:app && npm run test` 为前置。

## 启动

- [ ] 首启 3 屏 Onboarding 可完成 / 可跳过
- [ ] 二次启动直接进主 Tab，不再出现引导
- [ ] 设置 → 重新首启引导后重启可再走一遍

## 自选

- [ ] 行内 Sparkline + 涨跌色随「涨跌色」设置变化

- [ ] 新加自选 15s 内无失败红字（宽限）

## 个股详情

- [ ] 决策卡显示档位、偏多/偏空、论点、风险、legend
- [ ] K 线周期与副图指标可切换

## 扫描 / 尾盘

- [ ] 策略 Tab → 尾盘选股 → 选套餐 → 扫描出卡片
- [ ] 卡片可加自选 / 忽略 / 进详情

- [ ] 我的 → 自动化 可见 digest / eod_scan

- [ ] 盘后摘要（应用内 snackbar）可出现
- [ ] 设置 → 通知通道 Webhook 试发成功（若已配置）
- [ ] 告警触发后冷却期内不重复弹；可在「最近触发」恢复
