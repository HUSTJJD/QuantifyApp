# signals — 信号

## Purpose

把策略引擎输出的买卖信号，变成用户在自选/详情页能立刻看到的**行动提示**。

## Requirements

### R1 实时信号流

**规则**
- 行情刷新时对订阅标的重算信号
- 信号写入 `trade_signal` 表，UI 读最新一条
- 仅交易时段重算（非交易时段保留收盘信号）

**验收**
- 信号徽标在自选列表可见（买 / 卖）
- 点击详情可看理由与各策略贡献

### R2 信号可解释

**规则**
- 每个信号带 `reasons[]`（最多 3 条）与 `contributions[]`（策略 id / 方向 / 强度 / 权重）
- UI 展示「为什么买 / 卖」

**验收**
- 信号详情能看到「MA 金叉 + MACD 金叉」这类组合理由

### R3 信号历史

**规则**
- 按标的保存信号时间线
- 可回看「过去 7 天出现过几次买信号」

**验收**
- 信号历史页可按时间倒序浏览
