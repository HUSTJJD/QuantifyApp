# simulation — 模拟盘

## Purpose

用虚拟资金完整走一遍「信号 → 下单 → 持仓 → 盈亏」，为实盘前练手。

## Requirements

### R1 独立账户

**规则**
- 默认账户 + 每策略专属账户（`profileId` 隔离）
- 初始资金、现金、冻结、持仓、委托、成交全部落 SQLite

**验收**
- 重置账户后资金回到初始值、持仓清空
- 两策略账户互不影响

### R2 A 股交易规则

**规则**
- 整手 100 股（科创板除外）
- 卖出 T+1：今日买入不可卖
- 手续费：佣金 / 印花税 / 过户费
- 市价单即时成交（参考现价）

**验收**
- 今日买入后立即卖出被拒
- 卖出手续费含印花税

### R3 实时估值

**规则**
- 总资产 = 现金 + 持仓市值
- 当日盈亏、累计盈亏、收益率

**验收**
- 现价变动后总资产同步变化

### R4 自动交易

**规则**
- 策略 `autoTrade=true` 时，信号在交易时段自动下模拟单
- 受风控规则约束（仓位、最大持仓数）

**验收**
- 开启 autoTrade 后，信号出现会写入委托与成交
