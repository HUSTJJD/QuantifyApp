# alerts — 告警

## Purpose

在用户不盯着屏幕时，关键事件（价格、指标、信号）主动提醒。

## Requirements

### R1 价格告警

**规则**
- 阈值：高于 X / 低于 Y / 涨跌幅超过 Z%
- 交易时段内轮询检查
- 触发后写入 `alert_event` 表

**验收**
- 现价突破阈值后产生一条告警记录

### R2 信号告警

**规则**
- 策略产生 buy/sell 信号时提醒
- 可按策略开关

**验收**
- 开启后出现买信号即记录告警

### R3 告警历史与去重

**规则**
- 历史倒序可查
- 同一标的同一条件当日只提醒一次（可配）

**验收**
- 连续突破不重复轰炸

### R4 指标告警

**规则**
- 均线交叉（MA 快/慢金叉死叉）
- RSI 进入超买/超卖区（跨界才触发）
- 依赖本地已同步日 K；默认关闭，可在「我的 → 盯盘告警」开启

**验收**
- 开启后，自选股出现金叉产生一条告警
- 关闭后不再评估指标规则

### R5 规则管理与策略信号开关

**规则**
- 内置规则可开关；用户可添加价格上破/下破/涨跌幅规则
- 策略 buy/sell 信号可按策略静音

**验收**
- 添加自定义上破规则后，突破阈值产生告警
- 静音某策略后，其信号不再推送
