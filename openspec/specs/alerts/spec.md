# alerts — 告警

## Purpose

在用户不盯着屏幕时，关键事件（价格、指标、信号）主动提醒。

## Requirements

### R1 价格告警

**规则**
- 阈值：高于 X / 低于 Y / 涨跌幅超过 Z%
- 交易时段内轮询检查
- 触发后写入 `alert_event` 表

**验收**
- 现价突破阈值后产生一条告警记录

### R2 信号告警

**规则**
- 策略产生 buy/sell 信号时提醒
- 可按策略开关

**验收**
- 开启后出现买信号即记录告警

### R3 告警历史与去重

**规则**
- 历史倒序可查
- 同一标的同一条件当日只提醒一次（可配）

**验收**
- 连续突破不重复轰炸
