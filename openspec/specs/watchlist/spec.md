# watchlist — 自选

## Purpose

用户日常盯盘的主入口：收藏标的、分组管理、实时报价。

## Requirements

### R1 自选管理

**规则**
- 增删标的；分组（新建 / 重命名 / 删除）
- 组内排序；跨会话持久化（SQLite）

**验收**
- 重启后自选与分组仍在

### R2 实时列表

**规则**
- 显示最新价、涨跌幅；交易时段 15s 轮询
- 秒显本地缓存，失败保留缓存
- 有买卖信号时显示徽标

**验收**
- 进入页面立刻有价格（缓存），随后刷新为实时价

### R3 与个股页联动

**规则**
- 点击行进入个股详情
- 详情页可加/取消自选，返回列表即时更新

**验收**
- 详情页加自选后，列表无需手动刷新即可见
