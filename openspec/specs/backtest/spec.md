# backtest — 回测

## Purpose

在历史 K 线上复现策略，给出**可信**的收益与风险指标，避免「纸面赚钱、实盘亏钱」。

## Requirements

### R1 回放正确性

**规则**
- 逐 bar 回放，只允许用「当前及之前」数据（禁止前视）
- 默认用不复权 K 线 + 本地复权因子；或显式前/后复权
- 手续费：佣金 + 印花税（卖出）+ 过户费；可配置

**验收**
- 同一策略、同一标的、同一区间，两次回测结果一致
- 关闭手续费后收益率应严格高于开启手续费

### R2 绩效指标

**规则**
- 总收益率、年化收益、最大回撤、夏普、胜率、盈亏比
- 权益曲线（每日）
- 成交明细（时间、价格、数量、费用）

**验收**
- 权益曲线与成交明细对得上
- 最大回撤 ≥ 0 且 ≤ 100%

### R3 参数扫描

**规则**
- 对策略参数网格批量回测
- 输出按目标指标（如夏普）排序的 Top N

**验收**
- `maFast ∈ [5,10,20]` × `maSlow ∈ [20,60]` 能跑完并排序

### R4 样本外验证

**规则**
- 支持训练区间 / 验证区间划分
- 报告样本内外指标差异

**验收**
- 可一键切「样本内 / 样本外」视图
