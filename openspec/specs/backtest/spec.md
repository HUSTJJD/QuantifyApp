# backtest — 回测

## Purpose

在历史 K 线上复现策略，给出**可信**的收益与风险指标，避免「纸面赚钱、实盘亏钱」。

## Requirements

### R1 回放正确性

**规则**
- 逐 bar 回放，只允许用「当前及之前」数据（禁止前视）
- **默认用不复权 K 线 + 本地复权因子合成**（`loadBacktestSeries`）；禁止直接用上游已复权价
- 手续费：佣金（含最低 5 元）+ 印花税（卖出）+ 过户费；可配置
- 建仓必须同时满足「整手」「持仓比例预算」「本金 + 手续费可负担」三个约束；
  预算装不下理论最大手数时**回退手数成交**，不允许整笔静默放弃
- 撮合：信号收盘判定、次日开盘成交（默认 `execution: 'nextOpen'`）
- 权益 = 现金 + 持仓市值；公司行为在除权日调整现金 / 股数 / 成本基准

**验收**
- 同一策略、同一标的、同一区间，两次回测结果一致
- 关闭手续费后收益率应严格高于开启手续费
- 网络取数一律 `adjust: 'none'`；有因子时前复权系数与 `adjustCandles` 一致
- 除权场景下只承担交易成本：10 送 10 后平仓的往返盈亏 ≈ −双边费用，不得出现「卖价腰斩＝巨亏」

### R2 绩效指标

**规则**
- 收益：总收益率、年化收益（`barsPerYear` 按周期折算，禁止写死 252）
- 风险：最大回撤 + 最长回撤持续期、年化波动率、下行波动（索提诺）
- 风险调整收益：夏普（可按无风险利率折算超额）、索提诺、卡玛
- 交易质量：胜率、盈亏比、最佳 / 最差单笔、平均持有 bar 数、持仓占比（暴露率）
- 单笔成交带 `pnl / pnlPct / holdingBars`（按**净投入**口径结清：含分红下调、配股缴款上调）
- 权益曲线（逐 bar）、成交明细（时间、价格、数量、费用）
- 指标实现统一收敛到 `metrics.ts`（回测 / 组合 / 基准三层共用，避免口径漂移）

**验收**
- 权益曲线与成交明细对得上
- 最大回撤 ≥ 0 且 ≤ 100%
- 非日 K 周期的年化不得按 252 折算（周=52、月=12、分钟按 4 小时/日折算）

### R3 参数扫描

**规则**
- 对策略参数网格批量回测
- 输出按目标指标（如夏普）排序的 Top N
- 扫描与主回测必须共用同一套参数基线（资金、仓位、成本、撮合、公司行为），否则结果不可比

**验收**
- `maFast ∈ [5,10,20]` × `maSlow ∈ [20,60]` 能跑完并排序
- 扫描给出的最优组合，在主回测口径下复跑得到同一结果

### R4 样本外验证

**规则**
- 支持训练区间 / 验证区间划分
- 报告样本内外指标差异
- 与主回测共用参数基线

**验收**
- 可一键切「样本内 / 样本外」视图

### R5 同标的对照（买入持有）

**规则**
- 买入持有基准必须与策略同口径：**同初始资金、同费用模型、同撮合时机（默认 nextOpen）、同除权处理**
- 买入持有复用回测引擎的 `planBuy`（整手 + 费用预算约束）与 `applyCorpActionsAtBar`（分红/送转/配股）
- 资金不足一手时如实返回「未成交」，禁止假装全仓

**验收**
- 10 送 10 场景下买入持有不得出现 −50% 假亏损（否则会伪造策略超额收益）
- 零成本 + close 建仓时，买入持有收益 ≈ 标的区间涨幅
- 策略 = 买入持有时超额 = 0

### R6 基准对比

**规则**
- 对齐策略净值与基准（沪深300）净值
- 指标：超额收益、年化超额、跟踪误差、信息比率、**Beta、年化 Alpha、相关系数**
- 年化因子跟随策略周期（`barsPerYear`）

**验收**
- 策略 = 基准时信息比率 = 0、Beta = 1、Alpha = 0

### R7 多标的视角

**规则**
- 池回测为「各标的独立 In & Out」，其平均值不代表组合实盘表现
- 提供等权合成层 `portfolio.ts`：按 UTC 日对齐，逐日对有效标的收益等权平均并累乘为组合净值
- 合成结果必须标注「等权合成」，说明未考虑资金竞争与 `maxPositions`

**验收**
- 各标的权重相等的极端场景（全部同收益）：组合收益 = 单标的收益
- 样本区间不齐时给出 `fullOverlapPct`，不以前向填充冒充缺失标的

### R7 取数口径透明

**规则**
- `loadBacktestSeries` 返回 `barCount` / `rangeMs` / `periodHonored`，UI 直接展示而非自行估算
- 支持 `maxBars` 限定回测窗口，避免「本地历史长度因人而异」导致的样本不可复现
- 本地库仅存日 K 时，分钟周期请求必须标记 `periodHonored=false` 并提示退化为日 K

**验收**
- 同一 `maxBars` 下，本地 / 网络来源得到相同窗口长度

### R8 派生回测参数透传

**规则**
- `walkForward` / `gridSearch` / `runBuyHold` 各自将调用方的 `BacktestOptions`
  （资金、仓位、费用、撮合、公司行为、`barsPerYear`）**完整透传**给 `runBacktest`，
  不得在中间层做二次默认化

**验收**
- `gridSearch` 单组合结果与同参数 `runBacktest` 完全一致
- 传入 `execution: 'nextOpen'` 时，walkForward 的样本内首笔成交价为次根开盘价
